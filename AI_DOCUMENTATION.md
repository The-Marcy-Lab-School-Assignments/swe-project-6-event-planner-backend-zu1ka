**1. What did you ask the AI to help you with, and why did you choose to use AI for that specific task?**

I used AI to help me debug errors when starting the server. When the server crashed with syntax errors, I shared the error messages with AI to help me understand what was wrong and where to look in the code.

**2. How did you evaluate whether the AI's output was correct or useful before using it?**

I read through the suggested fixes and compared them to what I had written. I also tested the server after each fix to confirm it actually resolved the error before moving on.

**3. How did what the AI produced differ from what you ultimately used, and what does that tell you about your own understanding of the problem?**

The AI pointed me to the right files and lines where the errors were, but I still had to understand why the syntax was wrong and make the correction myself. It showed me that I understood the structure of the code but sometimes missed small syntax issues when copying code manually.

**4. What did you learn from using AI in this way?**

I learned that AI is useful as a debugging tool when you can read error messages and know what questions to ask.It helped me move faster through errors but I still had to understand the code to know whether the fix made sense.
